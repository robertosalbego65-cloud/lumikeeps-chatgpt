Privacy Policy — LumiKeeps Portrait Planner

Effective date: 8 September 2026

Publisher / data controller: ROBERTO SALBEGO

Privacy contact: roberto.salbego65@gmail.com

1. What this plugin does

LumiKeeps Portrait Planner helps users choose a personalized portrait concept and prepare reference photos. The public plugin does not sell products, process payments, place orders, access an Etsy account, or retrieve the user’s full ChatGPT conversation history.

2. Categories of personal data processed

The plugin processes only the brief task-specific text that ChatGPT sends to the plan_personalized_portrait tool. This may include information the user voluntarily provides about portrait subjects, relationships, occasions, or preferences. The tool does not require names, email addresses, phone numbers, postal addresses, precise location, account identifiers, payment data, passwords, government identifiers, health information, or other sensitive data.

The publisher does not intentionally collect IP addresses, device fingerprints, advertising identifiers, or behavioral profiles for this plugin. Hosting infrastructure may necessarily process limited network and security metadata to deliver the service and protect it from abuse.

3. Purposes of use

  • To process the task-specific request and return portrait-planning suggestions.
  • To maintain the security, availability, and technical reliability of the service.
  • To comply with applicable legal obligations where required.

Data is not used for advertising, cross-service tracking, behavioral profiling, or sale to third parties.

4. Recipients and service providers

Task data is processed by the publisher’s MCP server and the hosting provider used to operate that server. At the time of publication, the hosting provider is Render. The service does not send portrait-planning requests to Etsy, advertising networks, data brokers, or payment processors.

OpenAI separately processes information within ChatGPT under OpenAI’s own terms and privacy practices. This policy describes the publisher’s processing after a tool request reaches this MCP server.

5. Retention

The application does not write the content of portrait-planning requests to an application database and does not intentionally log the request text. Request content is processed transiently in memory for the duration of the request and then discarded by the application.

Technical hosting/security logs that do not contain the portrait-planning request text may be retained for up to 7 days, according to the hosting configuration and provider. Support correspondence, if a user contacts the publisher, is retained for up to 12 months after the support matter is closed, unless a longer period is legally required.

6. User controls and rights

Users can limit the data processed by avoiding personal identifiers in their portrait-planning request. Users may disconnect or uninstall the plugin at any time. Where applicable, users may request access, correction, deletion, restriction, objection, or other rights available under applicable privacy law by contacting the privacy address above. Because tool request content is not stored in an application database, there may be no stored request content to delete after a request has completed.

7. Children and sensitive information

The plugin is not directed to children under 13 and does not require sensitive or special-category personal data. Users should not include sensitive information that is unnecessary for portrait planning.

8. Security

The publisher uses reasonable technical and organizational measures to protect data in transit and to limit processing to what is necessary for the requested function.

9. Changes

If the plugin’s data practices materially change, this policy will be updated before the changed processing is introduced and the effective date will be revised.
